## CHARACTER SHEET

A blank character sheet for recording your Dungeon World character's class, stats, moves, and gear. Print this sheet or use the [interactive character generator](https://engine.moddable.games/play/?game=dungeon-world&variant=character-sheet) to create a new character with a randomised class and starting moves.
