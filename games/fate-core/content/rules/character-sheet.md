## CHARACTER SHEET

A blank character sheet for recording your Fate Core character's aspects, skills, stunts, stress, and consequences. Print this sheet or use the [interactive character generator](https://engine.moddable.games/play/?game=fate-core&variant=character-sheet) to create a new character with the skill pyramid and sample aspects.
